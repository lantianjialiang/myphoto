## 功能导览

### 1. 建索引（只读，不改任何文件）

- 添加任意本地文件夹、外接盘、网络映射盘作为「媒体源」，递归扫描并建立索引。
- 支持 JPEG / PNG / WebP / GIF / BMP / TIFF / HEIC / HEIF / MP4 / MOV / M4V / AVI / MKV / WMV / 3GP。
- **HEIC 可解码**（随包带 `lib\heif.dll`）：能出缩略图、读 iPhone 的原图与 EXIF。
- 增量扫描：按 路径+大小+mtime 判断，没变的文件不重复干活；源离线时保留索引，不误判成“已删除”。
- 不跟随符号链接与目录联接；单个损坏文件不影响整批，失败原因写日志。

### 2. 浏览

- **媒体库**：虚拟滚动的照片网格，缩略图 + 视频时长/LIVE/重复/收藏角标，支持列表模式，多选。
- **时间线**：年/月/日三档密度，分组标题吸顶，等高不等宽（justified）排版保留原始比例，
  “那年今日”快速回顾，无日期统一进「未知日期」。滚到底部自动续页（V1.4），不用手动点“加载更多”。
- **详情面板**：大图/视频预览、EXIF 与文件位置、日期候选与证据、标签、星标、单条改期。
- **视频封面本地抽取（V1.5）**：装了 FFmpeg 时由后端直接抽帧生成封面，
  浏览器解不了的编码（HEVC/AV1 等）也能正常显示，不再是 ▶ 占位；没装则自动回退浏览器抽帧。

### 3. 修日期（只写索引，不动 EXIF）

- 「待整理」工作台：全部 / 无日期 / 低可信 / 时间冲突 四种视图。
- 单条或批量指定日期时间、批量整体平移（±分钟/天）、从候选里一键采用。
- 识别顺序：人工覆盖 > EXIF 原始时间 / 视频容器时间 > 文件名 > 目录名 > 文件系统时间；**认不出来就留空，绝不填今天**。

### 4. 去重与相似

- **重复文件**：先按大小聚类再算完整 SHA-256，同内容合并成一组，列出每个副本路径与大小，可标记保留。
- **相似照片**：64 位 dHash + 汉明距离聚类，阈值可调（默认 6/64）。
- 两者都**只给提示，不提供删除**。

### 5. 时间水印（V1.2 ~ V1.5）

- 把拍摄时间（或自定义文字）烧进图片，字号按短边比例自适应，横图竖图视觉一致。
- 九宫格定位 + 边距 + 任意角度旋转；**画面方向校正**（0/90/180/270），竖拍但 EXIF 缺失的照片也能转正。
- **拖拽定位（V1.5）**：九宫格里选「✥ 拖动」后，直接在右侧预览图上按住水印拖动即可定位。
  位置按画面百分比记录，批量应用到不同尺寸照片时保持一致；贴边会自动收进画面内，不会裁掉。
- **自定义字体（V1.5）**：可以把 `.ttf/.ttc/.otf` 放进数据目录的 `fonts\`，或在界面上填完整路径，
  点「校验」确认可用后再用；系统字体下拉框里也会多出「我的字体」分组。图片与视频水印用同一套字体。
- 文字色/描边/阴影/不透明度/半透明底板/通栏底栏；三套内置预设（经典数码橙 / 简约白字 / 相框底栏）+ 自定义预设。
- 模板 `{date} {time} {filename} {camera}` + 第二行自定义文字，日期格式用 chrono 表达式。
- 三张不同尺寸样片并行对照预览，直接显示“这张图上的实际字号是多少 px”和“这张图的 EXIF 方向”。
- 批量输出：命名模板（`{YYYY}/{name}_wm.{ext}`）、JPEG 质量、保留/剥离 EXIF、同名跳过或自动加序号。
- **两种输出方式**：
  - 「新建副本」（默认）：写到指定目录，源文件一个字节都不改。
  - 「覆盖原图」（V1.3）：直接改写原文件，**默认先把原件备份**到 `数据目录\backups\wm-<任务ID>\`；
    只对 JPG/PNG/WebP/TIFF 生效，HEIC 会明确报错跳过（无法重新编码成 HEIC）。
- **视频也能烧（V1.4）**：把 `ffmpeg.exe` 放到程序目录（或 `lib\`、PATH）后，同一套参数会作用到视频上——
  重新编码为 H.264（`-crf` 18~24），音频原样复制，位置/字号用表达式按画面尺寸自适应，两行文字逐行定位不重叠。
  「设置 → 格式支持」会显示是否检测到 FFmpeg 及其版本；没装则视频被跳过并在任务消息里说明原因。
- **一键还原覆盖（V1.4）**：覆盖模式每批都会在 `watermark_backups` 里留记录，「覆盖记录」里可以看到
  批次时间、张数、占用空间，点「还原」把原件逐张写回（临时文件 + 原子替换），并同步刷新索引与缩略图；
  「删除备份」则只清备份、保留当前状态。
- 没有可靠拍摄时间的照片默认跳过，不把“今天”烧进老照片。

### 5b. 批量旋转 / 翻转（V1.5）

- 左侧导航「图像编辑」页，五个旋转翻转操作：右转 90° / 左转 90° / 转 180° / 左右翻转 / 上下翻转。
- 两种输出方式：**新建副本**（原图不动，写到你选的目录）或**覆盖原图**（默认先备份，可一键还原）。
- 覆盖模式下会自动更新索引里的宽高并清掉旧缩略图缓存，界面立刻显示转正后的图。
- 备份批次记在 `edit_backups` 表，「覆盖记录」里可整批还原或删除备份。
- 视频会被跳过；HEIC 不支持原地编辑（没有 HEVC 编码器），会明确报错。

### 5c. 裁剪 / 调色 / 打码（V1.6）

图像编辑页在旋转翻转之外，新增三类编辑，和旋转翻转共用一套“动作 → 批量应用 → 一键还原”的管线：

- **裁剪**：在右侧原图参照上拖框选区，或点比例预设（1:1 / 4:3 / 3:4 / 16:9 / 3:2 / 2:3）后选对齐方式
  （九宫格 / 中心）。选区按「画面百分比」记录，批量应用到不同尺寸照片时区域一致；可一键清除选区。
- **调色 / 滤镜**：亮度、对比度、饱和度、色温四个滑块，范围 −100~100，实时预览；
  批量时用同一组参数套到所有选中图。
- **局部打码**：在图上拖出矩形区域做**马赛克**或**模糊**（强度可调）。只改这一块，其余像素不动。
- 以上动作都支持「覆盖原图」（先备份、可整批还原）与「新建副本」两种方式；
  裁剪会改变尺寸，覆盖后会同步更新索引宽高与缩略图。

### 6. 归档（复制 / 移动 / 撤销）

- 模板化输出路径（默认 `{YYYY}/{YYYY-MM}/{original_name}`，无日期进 `Unknown-Date/`）。
- 先出 dry-run 计划：数量、字节、冲突、目标盘剩余空间。
- 复制：写临时文件 → 校验字节数 + SHA-256 → 原子重命名；同名默认跳过，绝不覆盖。
- 移动：同盘 `rename`（瞬时），跨盘退化为“校验复制 + 删源”，两种情况都即时更新索引。
- 撤销按**批次**：复制批次校验后删副本；移动批次校验后移回原位；目标被改过就拒绝并记失败。

### 7. 导出网页相册

- 生成自包含文件夹：`index.html`（含照片）+ `photos/` + `thumbs/`（未加密时），双击即离线浏览，不联网。
- 键盘左右切换、Esc 关闭、懒加载、“下载原图”（仅勾选附带原图时）。
- 页面里的图片全部重新编码并剥离 GPS；勾选附带原图会明确提示隐私风险。
- **多主题（V1.6）**：内置 dark / light / film / polaroid / mosaic 五套主题，导出时选一套即可。
- **密码保护（V1.6）**：勾选「顺便打包 zip」旁边可填密码。设了密码后，相册照片以大图/缩略图以
  **AES-256-GCM** 加密后内嵌进 `index.html`，双击打开会先要求输入密码，由浏览器本地（Web Crypto）解密后显示；
  **密码不写入任何文件**，也无法从文件里反推。注意：密码保护开启时不会附带未加密的原图。
- **可打包 zip（V1.4）**：勾选后顺手把整个目录压成同名 zip，放在输出目录旁边，直接发给别人即可。

### 7b. 合成幻灯片（V1.5）

- 顶栏「幻灯片…」：把当前选中的照片与视频拼成一段 **MP4 视频**或 **GIF 动图**。
- 每张照片停留几秒、每段视频截几秒、画布短边像素（480/720/1080）、补边背景色都可调。
- 照片与视频统一缩放居中、不裁切；GIF 走两遍编码（先出调色板再套用），颜色不会发脏。
- 需要 FFmpeg。没检测到时按钮直接置灰并说明原因，不会让你白等一场。

### 8. 任务与审计

- 扫描/哈希/复制/移动/水印/相册/撤销都是持久化后台任务：有进度、可取消、重启后标记中断、可重试。
- 「任务中心」看任务、「操作日志」看每次写入的源/目标/哈希/结果、「可撤销」看待撤销批次。
- 支持数据库一致性备份（`VACUUM INTO`）与 CSV / JSON manifest 导出。

## 运行

发布版**双击 exe 就能用**：`PhotoVideoManager.exe` 用 Windows 子系统编译，不会有黑色控制台窗口，
启动后自动开一个独立的“应用窗口”（Edge/Chrome 的 `--app` 模式，无地址栏、无标签页）。

之前需要 `启动.cmd` / `Start.ps1` 是因为两件事，现在都不需要了：

1. 旧版是控制台程序，双击会留一个黑框，中文还会因为代码页不对变乱码 —— 现在改成 GUI 子系统，
   只有从命令行启动时才把输出接回父控制台（`--no-window` 的重定向照旧可用）。
2. 旧版需要脚本先编译、并把 `lib\` 里的 HEIC 解码器拷到 exe 旁边 —— 现在发布包里就是编译好的
   exe + `lib\`，解压即用。

便携包里仍然保留 `启动.cmd` 作为“以命令行方式启动”的备选（想立刻看到日志时用）。

开发时：

```powershell
cargo build --release
.\Start.ps1                                  # 首次会自动编译，并同步 lib\ 到 target\release\
target\release\photo-video-manager.exe        # 直接双击/运行也行
target\release\photo-video-manager.exe --no-window --data-dir D:\pvm-data
```

`--data-dir` 指定数据库/缓存/备份目录；`--no-window` 只起本地服务并打印带 token 的地址。

首次使用：左侧「媒体源」→ 添加文件夹 → 自动开始扫描 → 「媒体库」查看。

### 打包交付

```powershell
powershell -ExecutionPolicy Bypass -File tools\package.ps1        # 编译 + 出便携目录 + zip
powershell -ExecutionPolicy Bypass -File tools\package.ps1 -Msix  # 额外尝试出 MSIX
```

产物在 `dist\`：

| 产物 | 说明 |
|---|---|
| `dist\PhotoVideoManager-1.6.0-win-x64\` | 便携目录，双击 `PhotoVideoManager.exe` 即用（不依赖 Rust、不需要管理员权限） |
| `dist\PhotoVideoManager-1.6.0-win-x64.zip` | 同一份内容的压缩包，约 3.4 MB |
| `dist\PhotoVideoManager-1.6.0-win-x64.msix` | 仅在加 `-Msix` 且本机有 Windows SDK 的 `makeappx.exe` 时生成；**未签名**，安装需自签证书 |

包里含主程序（约 6.1 MB）、`lib\` 解码器（约 1.9 MB）与第三方组件说明；删除 `lib\` 后程序照常运行，只是没有 HEIC 缩略图。

## 架构

```
Rust 单可执行文件
├─ 本地回环 HTTP 服务（127.0.0.1 + 随机端口 + 一次性 token，拒绝非本机 Host）
├─ SQLite 索引（WAL、事务、版本化 schema）
└─ 内嵌 Web UI（原生 HTML/CSS/JS，无构建步骤、无第三方前端库）
```

选择这条路线而不是 Tauri：界面同样是独立窗口、同样离线，但省掉 Node 构建链与 Tauri/WiX 打包依赖，
单文件即可运行，符合 PRD “不要第一版过度设计”的要求。

| 模块 | 职责 |
|---|---|
| `scan.rs` | 递归发现文件、排除规则、增量索引、缺失标记 |
| `media.rs` | EXIF 读取、MP4/MOV 容器解析、缩略图（含方向矫正） |
| `heif.rs` | HEIC/HEIF 解码：运行时加载 `heif.dll`，取宽高、EXIF 与缩略图，缺失时降级 |
| `dateinfer.rs` | 文件名/目录/文件系统/EXIF 多来源日期 + 置信度 + 冲突判定 |
| `dedupe.rs` | 大小聚类 → 完整 SHA-256 → 同内容资产合并 |
| `similar.rs` | 64 位 dHash 指纹 + 汉明距离并查集聚类（“相似”≠“重复”） |
| `livepair.rs` | Live Photo 配对：同源同目录同文件名主干，严格一对一 |
| `tags.rs` | 标签、星标、收藏（只存索引，不动文件） |
| `watch.rs` | 轮询源根目录 mtime，变化即排队增量扫描（不装文件系统钩子） |
| `watermark.rs` | 时间水印：字体加载、自适应字号、九宫格与自由定位、描边/阴影/底板、EXIF 方向与保留 |
| `edit.rs` | 批量旋转 / 翻转：复用水印的解码-编码管线，覆盖前备份、可整批还原 |

  **不跟随符号链接与目录联接**；单个损坏文件不影响整体；权限拒绝/长路径/损坏文件写入日志。
- **HEIC 解码**：内置 `lib/heif.dll`（libheif 1.23.7 + libde265 1.0.15，仅 HEVC 解码，约 2 MB），
  运行时动态加载，生成缩略图与预览，并从 HEIF 容器里取 EXIF（拍摄时间、机型、GPS）参与日期推断；
  支持 iPhone 的网格（grid）拼接图与 irot/imir 旋转属性；解码器缺失时自动降级为“只索引 + 明确原因”。
- **索引模型**：`media_assets`（逻辑资产，UUID）+ `media_files`（文件实体）分离，一个资产可对应多个路径。
- **增量与离线**：按 路径+大小+mtime 判断变化；完整扫描结束后才把未出现的文件标记 `missing`；
  源离线时保留全部索引并提示，不会误判为删除。
- **日期识别**：人工覆盖 > EXIF `DateTimeOriginal` / 视频容器创建时间 > 文件名 > 目录名 > 文件系统时间；
  保留原始候选、来源、置信度与 `offset`；QuickTime 按本地时间解释，MP4 按 UTC 转本地；无法识别则留空（**绝不填今天**）。
- **日期修复**：待确认工作台（全部 / 无日期 / 低可信 / 时间冲突）+ 详情内单条或批量覆盖，只写数据库。
- **完整去重**：先按大小聚类再算 SHA-256，同哈希资产合并；重复页展示每个副本路径、大小、日期，
  可打开所在文件夹或标记保留 —— **不提供删除**。
- **安全归档**：默认模板 `{YYYY}/{YYYY-MM}/{original_name}`，无日期进 `Unknown-Date/`；
  先出 dry-run 预览（数量、字节、冲突、目标可用空间）；复制写临时文件 → 校验字节数与 SHA-256 → 原子重命名；
  同名默认跳过绝不覆盖；输出目录若在源内会自动加入该源排除列表；路径做非法字符、保留设备名、目录穿越、长度防护。
- **任务与审计**：扫描/哈希/复制/移动/撤销任务持久化，支持取消、失败重试、重启后继续（已校验的条目不会重复复制）；
  `operation_log` 记录每次写入的源/目标/哈希/结果；数据库一致性备份（`VACUUM INTO`）；CSV 与 JSON manifest 导出。

### V1.1 新增

- **相似照片**：对缩略图算 64 位 dHash，按汉明距离并查集聚类；默认阈值 6/64，可实时调；同一 SHA-256 的完全重复会
  单独归到「重复文件」页、不再混进相似组。**只是候选提示，不提供任何自动删除**。
- **移动与重命名**：归档除“复制”外可选“移动”。同盘走 `rename`（瞬时、不产生副本），跨盘自动退化为
  “校验复制 + 删除源”；两种情形都会把索引里的路径即时改到新位置，不会把文件误判为“缺失”。
- **整批撤销**：按批次撤销（不是单条）。复制批次校验目标 SHA-256 与记录一致后删除副本；移动批次校验后移回原位置，
  原位置已存在同名文件时拒绝覆盖并记失败；撤销完写审计日志，已撤销的批次不再显示撤销入口。
- **目录变更监控**：定时（默认 300 秒，最小 30 秒）检查每个源根目录的 mtime，变化即排队一次增量扫描。
  不装文件系统钩子（NAS/外接盘/无管理员权限也能用），离线源跳过，同一源不重复排队。
- **批量时间偏移**：以当前显示日期为基准整体平移（±分钟/天），写入人工覆盖值、不改 EXIF；无日期的项跳过，不填今天。
- **标签 / 星标 / 收藏**：可单条或批量增删改；标签可重名复用、可重命名删除；列表、详情、筛选栏、
  导出 CSV/JSON 都带上这些字段。**全部只存在本地索引里**。
- **Live Photo 配对**：同源、同目录、同文件名主干的一张图 + 一段 MOV 自动配对，界面可手动作废；
  多对多一律跳过并计数，不猜。
- **并发健壮性**：写事务统一 `BEGIN IMMEDIATE` + 重试（避免先读后写导致 `SQLITE_BUSY_SNAPSHOT` 让整批扫描全废）；
  进程内保留一条常驻连接，避免 WAL 库“最后一条连接关闭时删除 `-wal`/`-shm`”与并发打开之间的竞态
  （表现为随机出现 `attempt to write a readonly database`）。

## 明确的限制（不伪称已实现）

- **HEIC/HEIF** 依赖随附的外置解码器 `lib\heif.dll`。删掉 `lib\` 目录后程序仍可正常使用，
  HEIC 会退化为“只索引、无缩略图”，并在界面给出具体原因。解码器只做 HEVC 解码，
  不支持 HEIC 内的 HDR 增益图重建（保留主图 8bit SDR 结果）与深度图。
- **视频播放**依赖 WebView/浏览器内核：H.264 MP4 正常，HEVC 需系统安装 HEVC 扩展，不支持时给出编码提示。
  视频封面优先由后端 FFmpeg 抽帧生成（浏览器解不了的编码也能出图）；没装 FFmpeg 时回退浏览器抽帧，
  浏览器也解不了时显示 ▶ 占位。
- **安装包**：已提供便携目录 + zip；MSIX 可出包但**未签名**（需要企业证书才能直接双击安装）。
  没有做 NSIS/WiX 安装器、没有做自动更新、没有做文件关联与右键菜单。
- **目录监控是轮询**：只比较源根目录的 mtime，因此最坏有一个轮询周期的延迟（默认 5 分钟）；
  深层子目录内新增文件不会改变根目录 mtime，需要靠周期性扫描或手动扫描补上。这是换成文件系统钩子的代价选择。
- **相似照片只对已算出指纹的项有效**：新扫描进来的文件要再点一次「计算相似指纹」；阈值全库统一，
  不支持按场景/人物做语义相似（没有 AI 模型，纯 dHash）。
- **移动不是可逆事务**：撤销依赖“目标文件哈希仍与记录一致”。撤销前若你改过或移走了目标文件，该条会被判失败并记入日志，
  需要手工处理 —— 宁可拒绝，也不猜。
- **水印不做“已有水印检测”**：同一张照片重复处理会叠两层水印，靠「跳过已存在文件」和命名模板避免。
  字体支持系统已安装的 TrueType/TrueType Collection，也可以指定自己的字体文件（**注意自行确认字体的授权许可**）；
  程序不打包字体，避免许可证问题。复杂文字排版（连字、双向文字、竖排）只按单字形推进宽度，不做完整 shaping。
- **EXIF 保留是“整段搬运”**：JPEG 直接复制 APP1 段，HEIC 重新包 APP1；不处理 XMP/ICC 的单独写入，
  也不支持按字段剔除（要保密就取消「保留 EXIF」，整段丢弃）。
- **网页相册不含局域网分享**：输出的是文件夹（可打包 zip），没有二维码、没有局域网分享。密码保护（V1.6）是“加密相册内容”，不是“联网分享”。
- **时间线分页加载**（每次 240 项）：不是全库虚拟滚动，超大库请用「媒体库」网格模式。
- 1 万文件的完整验收只在 3000 样本上测量过，未测试 NAS 与非 SSD 介质的具体耗时。

## HEIC 解码器（可选组件）

`lib\heif.dll` + `lib\libde265.dll` 是构建产物，不是系统组件：

| 项 | 说明 |
|---|---|
| 来源 | 源码构建（libheif 1.23.7、libde265 1.0.15），仅启用 libde265 的 HEVC 解码后端 |
| 体积 | 约 2 MB（相比发行版 libheif 需要连带 aom/x265/rav1e 等十余个 DLL，小一个数量级） |
| 加载方式 | 运行时 `LoadLibraryExW(..., LOAD_WITH_ALTERED_SEARCH_PATH)`，只从 `lib\` 找依赖，不改 PATH |
| 查找顺序 | `PVM_HEIF_DLL` 指定的文件 → `lib\heif.dll`（exe 同级/当前目录）→ `<数据目录>\lib\heif.dll` |
| 重新构建 | `bash tools/build-heif.sh`（需要 VS2022 C++ 工具链；源码解压到 `.cache\`） |
| 许可证 | libheif 与 libde265 均为 **LGPL-3.0**，随 DLL 附 `lib\LICENSE-*.txt`；动态链接，可直接替换 DLL |
| 测试样本 | `test\fixtures\heic\`：两张普通 HEIC + 一张 iPhone 11 Pro 原图（网格拼接 + EXIF），合计 1.7 MB |

## 数据位置

| 内容 | 路径 |
|---|---|
| 数据库 | `%LOCALAPPDATA%\PhotoVideoManager\library.db`（可用 `--data-dir` 改） |
| 缩略图/封面缓存 | `<数据目录>\cache\thumb\`（可删除，会自动重建） |
| 数据库备份 | `<数据目录>\backups\library-<时间戳>.db` |
| 水印覆盖前备份 | `<数据目录>\backups\wm-<任务ID>\<原文件名>`（任务完成时会打印完整路径） |
| 旋转翻转覆盖前备份 | `<数据目录>\backups\edit-<任务ID>\<原文件名>` |
| 自定义字体 | `<数据目录>\fonts\*.ttf`（放进去就能在字体下拉框里选到） |
| 崩溃日志 | `<数据目录>\logs\panic.log`（仅记录内部错误，不含照片内容） |
| 窗口配置 | `<数据目录>\window-profile\`（独立 Edge 配置，不影响日常浏览器） |

原文件默认只读：扫描、读元数据、生成缩略图/水印预览、算哈希都不写源文件。
写操作只有五处：

1. 「归档整理」：复制或移动到你指定的输出目录（移动会删源，可整批撤销）；
2. 「时间水印」副本模式：只写你指定的输出目录；
3. 「时间水印」覆盖模式：**会改写原文件**，默认先备份；
4. 「旋转翻转」覆盖模式：**会改写原文件**，默认先备份；
5. 「导出网页相册」与「幻灯片」：只写你指定的输出目录。

## 常见问题

**双击 exe 没反应？** 看 `<数据目录>\logs\panic.log`；多数情况是数据目录无写权限，或另一个实例正在占用数据库
（会有弹窗提示）。也可以先用 `PhotoVideoManager.exe --no-window` 跑一次，日志会打在控制台里。

**偶尔弹“本地服务暂时没有响应”？** 这是浏览器到本地 127.0.0.1 的请求短时间内没连上（比如刚从睡眠唤醒、
或后台正在处理大批量水印）。GET 请求会自动重试一次；持续出现就重启程序。

**升级后点按钮弹“接口不存在”？** 旧版浏览器缓存了旧脚本，V1.3 起静态资源已改为 `no-store`，重启窗口即可；
如果还出现，说明你运行的是包外的一个旧 exe。

**水印位置看着不对？** 先看预览卡片上的「EXIF 方向」：显示“无方向标记”而照片明显是竖着拍的，
说明这张图的 EXIF 方向丢了（常见于社交软件转发），把「画面方向」设成顺/逆 90° 即可。
